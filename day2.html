CONCEPT 01

DECISION MAKING: IF-ELSE & NESTED LOGIC

<CONTROL_FLOW>

Programs need to make choices based on data. Python uses if, elif, and else keywords to construct decision paths.

Decision Tree Architecture
1. Condition True / False
2. Block Runs if True
3. Fallback elif / else

Short-Circuit Evaluation:

• In A and B, if A is False, B is never evaluated.

• In A or B, if A is True, B is skipped immediately.

// nested_decision.py PYTHON 3.11 
age = 19
has_license = True

if age >= 18:
    # Nested condition inside primary block
    if has_license:
        print("Eligible to drive vehicle.")
    else:
        print("Age valid, but driver's license required!")
else:
    print("Underage. Driving restricted.")
Output: Eligible to drive vehicle.

CONCEPT 02

LOOPS & REPETITION MECHANICS

<ITERATION>

Loops allow executing a block of code repeatedly until a condition changes or a sequence is exhausted.

// FOR LOOP

Best for iterating over known sequences or predefined range limits.

for i in range(1, 5, 1): range(start, stop, step)
// WHILE LOOP

Executes indefinitely as long as condition evaluates to True.

while count < 5: Requires manual state updates!
CONTROL KEYWORDS:

• break: Immediately terminates loop execution.

• continue: Skips current iteration & moves to next.

• pass: Placeholder statement (does nothing).

// pattern_nested.py STAR PATTERN 
rows = 4

for i in range(1, rows + 1):
    for j in range(i):
        print("*", end=" ")
    print() # Newline after inner loop completion

CONCEPT 03

FUNCTIONS & VARIABLE SCOPE

<MODULARITY>

Functions are reusable blocks of code defined using def. They reduce duplication and build modular architecture.

KEY FUNCTION CONCEPTS:

• Parameters vs Arguments: Placeholders in definition vs actual values passed during invocation.

• Return Value: Sends data back to caller. Without an explicit return, functions yield None.

• Scope Rules (LEGB): Local -> Enclosing -> Global -> Built-in.

*args & **kwargs:
*args accepts dynamic positional arguments as a tuple.
**kwargs accepts dynamic keyword arguments as a dictionary.
// function_demo.py SCOPES & ARGS 
tax_rate = 0.18 # Global Variable

def calculate_total(price, discount=0):
    # Local variable calculation
    final_price = (price - discount) * (1 + tax_rate)
    return round(final_price, 2)

total = calculate_total(100, discount=10)
print(f"Final Amount: ${total}")
Output: Final Amount: $106.2

CRITICAL ⚠️

RECURSION: SELF-REFERENTIAL LOGIC

<CALL_STACK_MECHANICS>
"To understand recursion, you must first understand recursion."

Recursion is a technique where a function calls itself to break down a problem into smaller instances.

THE 2 MANDATORY RULES OF RECURSION:
1. BASE CASE (Termination) Condition that stops the function from calling itself. Without this, you trigger a RecursionError: maximum recursion depth exceeded.
2. RECURSIVE STEP (Reduction) The function call moving closer toward the Base Case.
// CALL STACK SIMULATION: factorial(3) LIFO STACK
factorial(3) → 3 * factorial(2) [WAITING]
factorial(2) → 2 * factorial(1) [WAITING]
factorial(1) → Returns 1 [BASE CASE HIT!]
Unwinding Stack: 1 × 2 × 3 = 6
CONCEPT 04

RECURSION IN PRACTICE

<CODE_PATTERNS>
// 1. Factorial Recursion 
def factorial(n):
    # Base Case
    if n == 1:
        return 1
    # Recursive Step
    return n * factorial(n - 1)
// 2. Fibonacci Recursion 
def fibonacci(n):
    # Base Cases
    if n <= 0: return 0
    if n == 1: return 1
    # Double Recursive Step
    return fibonacci(n - 1) + fibonacci(n - 2)

Write an algorithm to determine if a given integer n > 1 is prime. 

def is_prime(n):
    if n <= 1: return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True
#02 PALINDROME CHECKER (STRINGS / NUMBERS)

Check if a string reads the same backwards using slice notation [::-1]. 

def is_palindrome(s):
    cleaned = "".join(char.lower() for char in s if char.isalnum())
    return cleaned == cleaned[::-1]

def add(a, b): return a + b
